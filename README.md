# elecom-mouse-restarter

ELECOM Mouse Assistant をリスタートさせるためのスクリプトです。

## 対象ツール

[ELECOM Mouse Assistant](https://www.elecom.co.jp/support/manual_web/products/type_01/mouseassistant_6/?elparam=r_qma6-h-jp)

## 実行環境

- macOS Sequoia
- 動作確認済みバージョン: ELECOM Mouse Assistant バージョン 6

## 使い方

```bash
bash restart_mouse_assistant.sh
```
